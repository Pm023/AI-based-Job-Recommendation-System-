The CareerMatch AI Pipeline

CareerMatch AI is an explainable recommendation and career guidance system based on core topics from the B.Tech Computer Engineering AI syllabus.

End-to-End AI System Architecture
1. Resume / Profile Input
2. NLP Skill Extraction
3. Fuzzy Logic Matching
4. Weighted Scoring
5. Expert System Rules
6. Ranked Recommendations
7. Skill Gap & Path

1. Natural Language Processing

Unstructured resume text is converted into structured skill inventories via a lightweight 6-step NLP pipeline:

  • Lowercasing & Cleaning: Sanitizes punctuation while preserving special technical terms like C++.
  • Tokenization & Stopword Removal: Filters out non-informative English words.
  • Dictionary & Alias Mapping: Matches n-grams against our 45+ skill ontology dictionary.

2. Fuzzy Logic Skill Matching

Skill mastery is not binary (yes/no). We map textual proficiencies into continuous numerical membership values on \([0.0, 1.0]\):

Beginner = 0.25 · Basic = 0.40 · Intermediate = 0.60 · Advanced = 0.80 · Expert = 1.00

Fuzzy Membership Categories: 0.85-1.00 (Excellent), 0.70-0.84 (Good), 0.50-0.69 (Moderate), 0.30-0.49 (Low), 0.00-0.29 (Poor).

3. 5-Factor Weighted Score

To eliminate black-box opacity, the recommendation score is calculated using an explicit transparent mathematical formula:

Score = 0.40(Skill) + 0.20(Education) + 0.15(Experience) + 0.15(Interest) + 0.10(Location)

Each sub-score is stored separately in the database to allow step-by-step auditability during viva evaluation.

4. Rule-Based Expert System

Applies understandable IF-THEN rules to determine role suitability and generate human-readable recommendation explanations:

IF Python >= Intermediate AND SQL >= Intermediate THEN Backend Suitability = High
IF Missing High-Weight Skill THEN Add Improvement Warning
